
# Руководство пользователя

## Регистрация гостя

1. Откройте приложение «SHISHKA».
2. Нажмите кнопку **«Зарегистрироваться»**.
3. Заполните поля:
   - логин;
   - пароль;
   - ФИО;
   - номер телефона.
4. Нажмите кнопку **«Зарегистрироваться»**.

**Ожидаемый результат:** данные сохраняются в базе данных на сервере через Retrofit. Открывается экран входа.

## Вход в систему

1. Введите логин и пароль.
2. Нажмите кнопку **«Войти»**.

**Ожидаемый результат:** приложение получает токен и User ID, которые сохраняются в **SessionManager**. Открывается главный экран.

## Бронирование номера

1. Выберите номер комнаты из списка.
2. Нажмите на поле **«Дата заезда»** и выберите дату в календаре.
3. Нажмите на поле **«Дата выезда»** и выберите дату в календаре.
4. Нажмите кнопку **«Забронировать»**.

**Ожидаемый результат:** приложение отправляет через Retrofit POST-запрос на сервер с ID комнаты, датами и ID пользователя. Сервер создаёт запись в таблице `bookings`. Появляется сообщение «Бронирование успешно создано».

Схема процесса бронирования показана на рисунке ниже.

![Схема процесса бронирования](images/booking-flow.png)

## Просмотр бронирований (администратор)

1. Войдите под учётной записью `admin`.
2. Просмотрите полный список всех бронирований.
3. Нажмите на бронирование для просмотра детализации.

**Ожидаемый результат:** отображается номер комнаты, даты проживания, логин, ФИО и телефон гостя.

## Завершение работы

Нажмите кнопку **«Выйти»** в меню приложения или закройте приложение.

**Ожидаемый результат:** сессия завершается, токен и User ID удаляются из SessionManager. Данные сохраняются в базе данных автоматически.
