# Установка и настройка

## Системные требования

### Для Android-устройства гостя

| Параметр | Минимальное значение | Рекомендуемое значение |
|---|---|---|
| ОС Android | 8.0 (API 26) | 12.0 (API 31) |
| Оперативная память | 2 ГБ | 4 ГБ |
| Свободное место | 100 МБ | 200 МБ |
| Сетевое подключение | Wi-Fi / мобильный интернет | Wi-Fi |

### Для рабочей станции администратора

| Параметр | Минимальное значение | Рекомендуемое значение |
|---|---|---|
| Операционная система | Windows 10 Pro | Windows 11 Pro |
| Процессор | Intel Core i5 | Intel Core i7 |
| Оперативная память | 8 ГБ | 16 ГБ |
| Свободное место | 20 ГБ | 40 ГБ |
| Java | JDK 17 | JDK 17 |

### Для сборочной среды (Android Studio)

| Параметр | Значение |
|---|---|
| Android Studio | версия 2023.1 и выше |
| Gradle | 8.0 и выше |
| SDK Android | API 26+ |
| JDK | 17 |

## Установка приложения на Android-устройство

1. Передайте APK-файл `shishka-1.0.0.apk` на устройство.
2. Разрешите установку из неизвестных источников в настройках Android.
3. Установите приложение.
4. В файле `config.json` (или в `BuildConfig.java`) укажите адрес сервера:

```json
{
  "apiUrl": "https://api.shishka.local",
  "timeout": 30
}
```
