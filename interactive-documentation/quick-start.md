# Быстрый старт

Этот раздел поможет начать работу с мобильным приложением «SHISHKA» за несколько минут.

## Для гостя

1. Установите APK-файл приложения на Android-устройство (Android 8.0+).
2. Запустите приложение «SHISHKA».
3. Нажмите кнопку **«Зарегистрироваться»**.
4. Заполните поля: логин, пароль, ФИО, номер телефона.
5. Войдите в систему, используя созданные логин и пароль.
6. Выберите номер комнаты и даты заезда/выезда через календарь.
7. Нажмите кнопку **«Забронировать»**.

> **Важно:** перед бронированием убедитесь, что дата выезда позже даты заезда, а номер свободен на выбранный период.

## Для администратора

1. Войдите в систему под учётной записью `admin`.
2. Просмотрите полный список всех бронирований.
3. Нажмите на бронирование, чтобы увидеть детализацию данных гостя.
