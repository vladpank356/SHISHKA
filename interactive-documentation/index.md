# SHISHKA — мобильное приложение для автоматизации отеля

**SHISHKA** — мобильное приложение для Android, разработанное в **Android Studio**, предназначенное для управления бронированием номеров в отеле. Приложение позволяет гостям регистрироваться, входить в систему, выбирать номер и даты проживания, оформлять бронирование, а администратору — просматривать все бронирования с детализацией данных о госте.

## Назначение

Приложение предназначено для автоматизации процесса бронирования номеров в отеле. Гость может самостоятельно выбрать номер и даты через мобильное приложение, а администратор — получить полную информацию о бронировании и связаться с гостем.

## Основные возможности

- Регистрация и авторизация пользователей (гость, администратор);
- Просмотр списка номеров отеля;
- Выбор дат заезда и выезда через календарь;
- Создание бронирования номера;
- Просмотр администратором всех бронирований;
- Детализация данных гостя: логин, ФИО, номер телефона;
- Работа через Retrofit с REST API на Spring Boot.

## Технологический стек

- **Среда разработки:** Android Studio;
- **Язык:** Java / Kotlin;
- **Клиент-серверное взаимодействие:** Retrofit;
- **Хранение сессии:** SessionManager;
- **Backend:** Spring Boot (Java);
- **База данных:** PostgreSQL.
